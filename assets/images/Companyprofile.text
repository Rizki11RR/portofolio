#Judul
Teknohaslink Company Profile CMS


#Deskripsi
Website company profile dinamis untuk perusahaan Teknohaslink dengan panel admin CMS yang komprehensif. Memungkinkan pengelolaan seluruh konten website (hero banner, layanan, portofolio, tim, mitra, sertifikasi) melalui admin panel tanpa perlu menyentuh kode. Dilengkapi fitur keamanan seperti URL admin tersembunyi, rate limiting, dan audit log otomatis.


#Stack Teknologi
PHP
Laravel
Tailwind CSS
MySQL
Docker
